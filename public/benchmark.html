📖 Panduan Fungsi & Ekspektasi Pengujian Tombol
⚡ Single UDP Datagram (1 Log)
Mengirim 1 paket log secara asinkron via soket UDP ke port 5001. Membuktikan latensi ultra-rendah tanpa menunggu database.
Ekspektasi: Total durasi < 5ms, log masuk antrean buffer RAM.
🚀 Batch Trigger (100 Logs)
Menembakkan 100 paket berturut-turut untuk menguji batas ambang (*batch threshold*) Aggregator.
Ekspektasi: Memicu Bulk-Insert SQL sekaligus ke PostgreSQL begitu paket ke-100 tiba.
🔥 High Load Burst (1,000 Logs)
Menembakkan 1.000 paket dalam microsecond loop server untuk menguji throughput tinggi (>50.000 paket/detik).
Ekspektasi: Antrean buffer melonjak lalu dikosongkan secara bertahap dalam ~100ms.
💥 Stress Blast (5,000 Logs)
Membanjiri soket dengan 5.000 paket sekaligus untuk menguji batas buffer soket OS dan ketahanan memori RAM.
Ekspektasi: Dapat memicu packet loss di OS, menguji self-healing bekerja di bawah tekanan berat.
🎯 Simulate Drop 2 Packets (Zero-RTT)
Sengaja melompati sequence ID (+3) untuk membuktikan Metode 3 Piggybacking.
Ekspektasi: Paket hilang langsung dipulihkan seketika dari payload cadangan paket berikutnya (0ms RTT).
🔄 Simulate Drop 9 Packets (TCP NACK)
Sengaja melompati sequence ID (+10) untuk menguji Metode 1 NACK Selective Retransmission.
Ekspektasi: Aggregator membuat request TCP ke Ring Buffer RAM API untuk menarik ulang 9 paket hilang.
🚨 Simulate Error 500 (TCP Fallback)
Mengirim log error status 500 untuk menguji Metode 2 Circuit Breaker.
Ekspektasi: Otomatis mem-bypass soket UDP dan dikirim via TCP HTTP Ingestion (Jaminan anti-hilang 100%).
💓 Manual Heartbeat Ping
Menembakkan sinyal detak jantung (*HEARTBEAT*) ke port 5001.
Ekspektasi: Mereset timer Watchdog (15s) dan memastikan badge Watchdog tetap hijau (OK).
🐢 Sync DB Logging (10 / 50 Logs)
Menulis log secara sinkron langsung ke database satu per satu (arsitektur monolitik konvensional).
Ekspektasi: Latensi lambat (~10-20ms per log), menunjukkan mengapa arsitektur UDP jauh lebih unggul.
🧹 Purge All Persisted Logs
Mengeksekusi endpoint DELETE /logs untuk mengosongkan tabel telemetry_logs.
Ekspektasi: Mengembalikan total log di database menjadi 0 baris seketika.
