📖 Panduan Lengkap & Ekspektasi Pengujian 16 Tombol
⚡ Single UDP Datagram (1 Log)
Maksud Awam: Mengirim 1 catatan kilat tanpa menunggu database. Membuktikan server merespon dalam sekejap mata (~0.2ms).
👀 Lihat di Layar: Kotak hijau baru bertuliskan Seq #X muncul di bawah.
🚀 Batch Trigger (100 Logs)
Maksud Awam: Menembakkan 100 catatan berturut-turut. Server menampungnya di RAM dulu, lalu menyimpannya sekaligus ke database begitu genap 100.
👀 Lihat di Layar: Angka antrean RAM naik lalu kembali 0, dan database bertambah 100 baris.
🔥 High Load Burst (1.000 Logs)
Maksud Awam: Menembakkan 1.000 data dalam sekejap mata untuk membuktikan server tidak macet saat gudang sedang sangat ramai.
👀 Lihat di Layar: Grafik biru RAM melompat tinggi dan log database bertambah +1.000 baris.
💥 Stress Blast (5,000 Logs)
Maksud Awam: Uji beban ekstrem menembakkan 5.000 data sekaligus seperti jutaan barang discan bersamaan. Membuktikan memori komputer kuat dan tidak jebol.
👀 Lihat di Layar: Terminal log meluncur sangat cepat dan grafik memori bergelombang.
🎯 Simulate Drop 2 Packets (Zero-RTT)
Maksud Awam: Pura-pura 2 data hilang di jalan karena internet kedip. Data berikutnya otomatis menggendong salinannya sehingga langsung pulih seketika (0 detik).
👀 Lihat di Layar: 2 kotak merah bertuliskan ⚠️ Hilang seketika berubah jadi UNGU bertuliskan 🔄 Pulih (0-RTT).
🔄 Simulate Drop 9 Packets (TCP NACK)
Maksud Awam: Pura-pura 9 data hilang sekaligus. Karena terlalu banyak untuk digendong, penerima langsung menelepon balik pengirim via TCP untuk minta salinannya dari RAM.
👀 Lihat di Layar: 9 kotak merah bersamaan berubah jadi UNGU bertuliskan 🔄 Pulih (TCP NACK) dan angka Recovered bertambah +9!
🚨 Simulate Error 500 (TCP Fallback)
Maksud Awam: Pura-pura sistem error fatal. Sistem pintar tahu data error itu SANGAT PENTING, jadi otomatis dialihkan ke jalur darurat khusus (TCP VIP) yang 100% anti-hilang.
👀 Lihat di Layar: Muncul kotak khusus bertuliskan ✕ 500 (TCP Fallback).
💓 Manual Heartbeat Ping
Maksud Awam: Mengecek detak jantung server utama. Memberi tahu penerima bahwa server masih hidup agar lampu status tidak berubah merah.
👀 Lihat di Layar: Lampu status Watchdog di kanan atas tetap berwarna HIJAU (OK).
🚀 Autocannon UDP Route (10s, 100 Conn)
Maksud Awam: Robot menirukan 100 orang membuka sistem bersamaan tanpa henti selama 10 detik di jalur cepat UDP WMS Nexus.
👀 Lihat di Layar: Muncul tabel hasil yang menunjukkan sistem mampu melayani ribuan request/detik tanpa lemot!
🐢 Autocannon Sync DB Route (5s, 50 Conn)
Maksud Awam: Menirukan 50 orang memakai sistem model lama yang harus antre menulis database satu per satu. Membuktikan cara lama jauh lebih lambat.
👀 Lihat di Layar: Angka kecepatan request/detik terlihat jauh lebih rendah dan latensi membengkak.
⚡ Quick Autocannon Blitz (3s, 25 Conn)
Maksud Awam: Uji kecepatan kilat 3 detik saja jika ingin demo cepat tanpa menunggu 10 detik penuh.
👀 Lihat di Layar: Tabel performa kilat langsung muncul di terminal bawah.
📋 Copy Terminal CLI Command

👀 Lihat di Layar: Muncul pesan bahwa teks perintah berhasil disalin.
🐢 Sync DB Logging (10 / 50 Logs)

👀 Lihat di Layar: Tombol terasa ada jeda loading beberapa ratus milidetik.
🧹 Purge All Persisted Logs
